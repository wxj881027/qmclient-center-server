# 公开 JSON 读取收口

2026-10-18 已在实际部署上收口 QmClient 的公开 HTTP 读取入口。

- 中心服务只监听 127.0.0.1:8080，避免绕过反向代理读取 HTTP 接口。
- HTTPS server 加载 qmclient-no-public-json.conf，相关 GET/HEAD 返回 404。
- 拦截范围包含 api/v1 查询、旧识别、时长、健康、版本、编辑器 HTTP 与服务器列表镜像。合法 POST 与 WebSocket 升级保留。
- HTTP 称号资料读取与 Qm 镜像读取也会停止；称号资料由现有 WebSocket 提供，客户端服务器列表仍有其他来源。
- 语音部署的旧识别接口此前已删除；本次将其健康检查额外限制为回环来源。

实际验证：Nginx 配置检查通过，中心服务 JavaScript 语法检查通过；中心、语音及 Nginx 均为 active。本机两个健康检查均为 200，外网检查的相关读取入口返回 404，主通道、编辑器与语音 WebSocket 握手均返回 101。

线上语音服务按原有源码增量构建 Release，单 job；构建成功，有一项原有 dead_code 警告。公开语音仓库仍包含旧 HTTP 识别协议，本次另以聚焦 PR 删除，不将线上其他未同步改动混入该 PR。新增相关测试，未执行单元测试；未启动游戏客户端验证。

部署前源码、二进制和 Nginx 站点配置保存在部署主机的本次任务备份目录中，不包含于 Git 提交。
