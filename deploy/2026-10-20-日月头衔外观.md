# 日月头衔外观

`POST /api/v1/titles/profile` 增加可选的 `appearance`，与原有用户文字和昵称绑定一起保存：

```json
{
  "title": "自选文字",
  "bound_name": "",
  "appearance": {"style": "sun", "color": 12420653, "opacity": 100}
}
```

- `style` 只接受 `moon`、`sun`。
- `color` 是 0 至 16777215 的 RGB 整数。
- `opacity` 是 0 至 100 的整数，0 是有效值。
- 无效外观返回 `400 invalid_appearance`，不更新文字或任何资料字段。
- 未提交 `appearance` 的旧请求保留已经保存的外观。
- 无外观的旧资料按紫色月亮返回，不批量改写数据库。

资料读取、兑换响应和 `List` 在场数据均携带同一对象；现有 WebSocket `title_profile`、`titles` 转发这份数据。本体和分身共用同一认证资料，原有昵称绑定和 15 秒租约继续生效。

部署涉及 `title_auth.js` 和新增 `title_appearance.js`，不需要依赖安装或数据迁移。回退时恢复原 `title_auth.js` 即可；新增资料字段可保留，旧实现会忽略它。
